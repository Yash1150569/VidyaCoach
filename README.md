# 🚀 VidyaCoach – AI Powered Career Coach

An AI-powered career guidance platform that helps students and job seekers make informed career decisions through personalized recommendations, AI-generated resumes, cover letters, mock interviews, and career roadmaps.

---

## 📌 Overview

VidyaCoach is a full-stack web application designed to simplify career planning by leveraging Artificial Intelligence. It provides users with personalized career insights, resume optimization, interview preparation, and AI-powered content generation through an intuitive and responsive interface.

---

## ✨ Features

- 🔐 Secure User Authentication using Clerk
- 🤖 AI-Powered Career Recommendations
- 📄 AI Resume Builder and Resume Analysis
- 📝 AI Cover Letter Generator
- 🎯 Personalized Career Roadmaps
- 💼 Mock Interview Preparation
- 📊 Performance Dashboard & Progress Tracking
- 📈 Interview Quiz Analytics
- 🌙 Modern Responsive UI
- ⚡ Fast and Scalable Architecture

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/Yash1150569/VidyaCoach.git
```

Navigate to the project folder

```bash
cd VidyaCoach
```

Install dependencies

```bash
npm install
```

Create a `.env.local` file and configure the required environment variables.

Run the development server

```bash
npm run dev
```

Open your browser and visit

```
http://localhost:3000
```
